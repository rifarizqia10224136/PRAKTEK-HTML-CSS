🚀 What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It acts as the skeleton or foundation of every website.

Key Points

  • HyperText: Text connected through links.
  • Markup: Defines the structure and meaning of content.
  • Language: Rules and syntax for creating web pages.

How HTML Works

HTML uses tags to define elements. Most tags have opening and closing tags.

<tagname>Content goes here</tagname>
<h1>This is a heading</h1>
<p>This is a paragraph</p>

📄 Basic HTML Structure

Every HTML document follows this basic structure:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>This is my first paragraph.</p>
</body>
</html>

Structure Breakdown

  • <!DOCTYPE html>: Declares HTML5.
  • <html>: Root element of the page.
  • <head>: Contains metadata.
  • <body>: Contains visible content.

⚙️ HTML Attributes

Attributes provide additional information about HTML elements.

  • id: Unique identifier for an element.
  • class: Groups elements for styling.
  • src: Specifies a source file.
  • href: Specifies a link destination.
  • alt: Alternative text for images.
  • style: Adds inline CSS styling.
